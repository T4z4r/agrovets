# App Access Information

## Any other information required to access your app

The Apex app requires user authentication via email and password to access its features. There are no additional access restrictions beyond standard login credentials.

### Access Requirements:
- **Username/Email**: Required for login
- **Password**: Required for login

### No Additional Restrictions:
- No 2-step verification
- No QR codes required
- No location-based access restrictions
- No memberships required
- No biometric logins (fingerprints, face recognition, etc.)

### Demo/Test Access:
For app review purposes, you can register a new account using the registration screen, or contact the developer for test credentials if available.

### Instructions:
1. Launch the app
2. Tap on the login option
3. Enter a valid email address and password
4. Access the app features based on user role (owner or seller)
